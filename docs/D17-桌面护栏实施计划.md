# D17 桌面护栏实施计划

- 微信、QQ 邮件和通用桌面任务共享桌面控制状态。每次改变焦点、输入、粘贴、清草稿、发送或提交前核对控制权和输入代次。状态不可读时停止。
- 微信发送前重读会话、草稿及生成回复时的消息，出现新消息则放弃旧候选。邮件重查原邮件、收件人和正文。通用任务只允许可读回目标与内容的发送或提交；其余交接。发出后结果不明时保留账本，禁止重发。
- 真人操作使旧许可失效。空闲五秒且按键均已松开后，当前任务最多重新观察并续跑一次。再次抢占交接。
- 托盘按钮与 Ctrl+Alt+F12 共用持久急停状态。仅托盘手动恢复，恢复时重新观察。快捷键冲突在托盘和日志提示。覆盖默认和旧微信发送入口。
- 验收包括三条入口合计二十次鼠标抢占全部让出，键盘抢占，二次中断，待发送急停，重启保持锁定，手动恢复，旧回复丢弃和结果不明不重发。微信使用文件传输助手和双向测试账号，邮件和通用任务使用测试目标。
- 保留 D16 回复修复，独立工作树实施，分别记录离线和真机结果。
