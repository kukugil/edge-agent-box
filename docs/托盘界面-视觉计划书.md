# 托盘界面视觉计划书（参照 Nomadic Tribe 风格）

参照：<https://2019.makemepulse.com/>（makemepulse 2019 年的互动作品 *Nomadic Tribe*）。
只借它的**气质和手法**，不搬它的插画、字体文件和版式原图；所有插画元素都要重新画，主题换成"电脑助手"自己的东西。

## 一、目标和范围

- 对象：`agent/desktop.py` 的托盘主窗口（电脑助手 + 待我处理 + 详情）和 `agent/assistant/widget.py` 的模型配置对话框。
- 只改外观和布局，**不改任何功能和逻辑**。现有控件一个都不能少：模型下拉、新增 API / 编辑 / 测试连接、对象输入框、任务输入框、开始 / 停止、状态、API 用量、接管提示、待处理列表、触发消息与后续消息、聊天截图、"已处理，恢复自动回复"按钮。
- 必须能用 PySide6 做出来（见第九节）。
- 这一版先出预览图，用户确认后再改程序。

## 二、参照网页的风格拆解

| 手法 | 原站的样子 | 我们怎么用 |
|---|---|---|
| 纸张底 | 米白底上有细密颗粒，像印刷纸 | 整个窗口铺纸纹底，颗粒很淡，不影响读字 |
| 雾色调 | 雾蓝灰、晨粉、冰晶蓝，饱和度都压得很低 | 照搬这种低饱和配色思路，见第三节色板 |
| 装饰窗框 | 新艺术风格：中间一个大圆拱，两边两扇竖窗，双线描边加小角饰 | 窗口做成"三联窗"：左窗是电脑助手，中间圆拱是当前状态舞台，右窗是待我处理 |
| 线稿插画 | 深蓝灰线条加平涂色块，没有渐变 | 舞台里画一组线稿：一块屏幕、一只指针、一张便签 |
| 粗体大标题 | 很粗的圆角几何字，横跨在窗框下沿 | "端侧盒子"四个字用超粗字，压在三联窗下沿 |
| 对白框 | 白底小框，细边框加错位投影，像漫画旁白 | 助手的状态句放进对白框，像助手在说话 |
| 按钮 | 深蓝灰实心块，里面再描一圈细线 | 主按钮照这个做；次按钮是纸色底加同色细线 |

## 四、字体

- 大标题："端侧盒子"、各区标题用超粗黑体。首选 **HarmonyOS Sans SC Black**，备选阿里巴巴普惠体 Heavy（两者都可免费商用，打包进程序）。拉丁字母和数字同一字体。
- 正文：微软雅黑（系统自带），14px，行高 1.6。
- 小字：12px，不低于 12px。
- 不用全大写英文标签，不用等宽字体。

## 五、布局

窗口 1280 × 760，三联窗结构：

```
┌──────────────────────────────────────────────────────────┐
│  ┌────────┐   ╭──────────────────────╮   ┌────────┐      │
│  │ 左窗    │   │      中间圆拱：舞台     │   │ 右窗    │      │
│  │ 电脑助手 │   │  线稿插画 + 对白框状态   │   │ 待我处理 │      │
│  │ 任务输入 │   │  看 · 想 · 做 · 核对   │   │ 列表     │      │
│  │ 模型    │   │  四枚圆章表示进度        │   │ 角标     │      │
│  │ 开始/停止│   │                      │   │         │      │
│  └────────┘   ╰──────────────────────╯   └────────┘      │
│        ▇▇▇ 端 侧 盒 子 ▇▇▇（超粗大字压在窗框下沿）            │
│  底部一行小字：API 用量 / 动鼠标即可接管                      │
└──────────────────────────────────────────────────────────┘
```

- 左窗（宽约 300）：标题"电脑助手"，任务输入（纸亮底，只有底线），对象输入，模型下拉加"新增 / 编辑 / 测试连接"三个文字按钮，主按钮"开始任务"，次按钮"停止"。
- 中间圆拱（宽约 520）：
  - 运行中：插画舞台，对白框写当前状态（如"已点击 12，等界面出现数字"），下方四枚圆章（像盖印）按"看、想、做、核对"排列，每枚章里写一个字；做完的盖苔绿，当前的是冰蓝实心，没到的是空心线稿。
  - 空闲：插画安静，对白框写"告诉我要做什么"。
  - 查看待处理时：圆拱里换成该会话的详情——聊天截图位、触发消息、后续消息，底部"已处理，恢复自动回复"主按钮。
- 右窗（宽约 300）：标题"待我处理"加琥珀角标；每项是一张"小签条"（纸亮底、细边、错位投影），写联系人、原因、时间；选中项底色变晨粉。
- 模型配置对话框：同样的纸底和双线窗框，表单单列，标签在上。

### 方案二：全幅绘本场景（第三轮，替代三联窗）

三联窗的问题：画被关在框里当装饰，界面还是一张表单，不够酷。方案二反过来——**画是整个窗口，界面是贴在画上的纸**。

```
┌──────────────────────────────────────────────────────────┐
│ 黄昏天空（慢速视差）            ┌ 晾绳 ─────────────────┐ │
│ ┌──────────┐                   │ [签]测试好友A [签]测试好友B │ │
│ │ 钉在画上的 │     城市剪影        └──── 待我处理签条 ──────┘ │
│ │ 任务便签   │   ╭对白框╮                                  │
│ │ 输入/模型  │   ╰──┬──╯   显示器发冰蓝光                    │
│ │ 开始/停止  │        机械小手 → 屏幕                       │
│ └──────────┘    ═════════ 书桌 ═════════                   │
│ 端侧盒子（超粗字，压在画面左下）   [看][想][做][核对] 圆章在桌沿 │
└──────────────────────────────────────────────────────────┘
```

- 插画铺满 1280 × 760：天空和城市在最底层，书桌、显示器、小手在中间，界面在最上层。
- 黄昏光：显示器屏幕发冰蓝色的光，照亮小手和桌面一小圈；画面四角压暗一点，视线集中到屏幕。
- 电脑助手：一张钉在画面左侧的大便签（纸亮底，略微倾斜 −1.5°，顶上一枚图钉），里面放任务输入、对象、模型、开始 / 停止。
- 待我处理：画面右上方一根晾绳，每个待处理会话是一张夹在绳上的小签条，角标是琥珀色夹子。点开签条，签条放大成一张信纸盖在画面右半边，显示详情和"已处理，恢复自动回复"。
- 状态：对白框从机械小手那里冒出来。
- 进度：四枚圆章立在桌沿，做完一步就"盖"一下。
- "端侧盒子"超粗字压在画面左下，像绘本封面标题。
- API 用量和接管提示：画面底边一行小字，压在半透明纸带上。

### 方案三：留白的全幅场景（第四轮，替代方案二）

方案二太挤：字太多，"端侧盒子"大字和"看、想、做、核对"四枚圆章没有信息量。第四轮只做减法：

- 去掉"端侧盒子"大标题和四枚圆章。进度只靠两样东西表达：机械小手指在哪里，对白框里一句话。
- 便签只留：一个任务输入框（占位字"告诉我要做什么"）、一个模型小标签、一个按钮（空闲是"开始"，运行中变"停止"）。不写"电脑助手""任务""模型"这些标签；"新增 / 编辑 / 测试连接"收进模型标签的下拉菜单。
- 晾绳签条只写联系人和时间；原因、消息和恢复按钮都放到点开后的信纸里。
- "待我处理"四个字缩成晾绳左端的一个小数字角标（玫瑰色木夹上写数字）。
- 底边小字只在运行中出现一句"动一下鼠标即可接管"；API 用量收进模型下拉菜单。
- 画面一半以上是安静的插画，界面元素不超过画面三分之一。
- 场景换成绿色调：窗外是傍晚的青绿天色和层层灰绿山丘（不画具体植物），远处一点雾紫云和极少的粉沙晚霞。

### 第五轮补充：拖动视角和 AI 小宠物

**拖动视角**（参照原站按住拖动时镜头跟着转的效果）：
- 按住画面空白处拖动，整幅场景跟着转一个小角度：远景山丘移动最少，书桌和小宠物居中，便签、签条这些纸移动最多，看起来像有景深。左右最多转约 6°，上下约 3°。
- 松手后像弹簧一样慢慢回到正中（约 800ms）。
- 不按住时，鼠标在窗口里移动也会让画面轻微跟随（幅度是拖动的三分之一）。
- 在输入框、按钮、签条上按下时不触发拖动，避免和正常操作冲突。
- 系统开启"减少动态效果"时关掉。

**AI 小宠物**（替代机械小手）：
- 一只原创的小机器人：身体圆滚滚、比显示器矮，一对会眨的大眼睛，一只能伸长的小手臂用来指屏幕。气质参考"可爱、笨拙、认真干活"的小机器人，但造型必须原创，不照搬任何电影角色的外形（不用方盒身体加履带、不用双筒望远镜眼睛）。
- 配色：沙纸色身体、深苔和青绿色细节，一点玫瑰色点缀（比如脸颊）。
- 分层出图：身体、头、眼睛（睁 / 闭 / 开心弯眼三种）、手臂，方便单独做动画。
- 表情对应状态：空闲时眼睛跟着鼠标看，偶尔眨眼；运行中盯着屏幕、手臂去点；完成时眼睛弯成开心；出错或停止时眼睛变成小横线、手臂收回。

## 六、组件规范（第四轮）

- 便签：沙纸底，左上一枚图钉，倾斜 −1.5°，右下 3px 错位实色投影（夜蓝 30% 透明度）。没有窗框。
- 主按钮（开始）：深苔实心，高 40，圆角 6，里面 3px 处描一圈沙纸亮色 1px 细线，文字沙纸亮色加粗。
- 停止按钮：沙纸亮底，赭红 1px 边和赭红字，外圈一道转动的青绿细线。
- 输入框：沙纸亮底，只有 1.5px 夜蓝底线；聚焦时底线变青绿、加粗到 2px。
- 模型标签：沙纸亮底小圆角标签，夜蓝字，右侧小三角；下拉菜单里是模型列表、新增 / 编辑 / 测试连接、API 用量。
- 对白框：沙纸亮底，1px 墨色边，右下 3px 错位投影，一个小三角指向机械小手。
- 角标：玫瑰色木夹上写墨色数字。
- 动效见第八节，按"每个动作都有回应、平时安静"的原则来。

## 七、绘本插画（用 Codex 生图）

线稿 SVG 撑不起"绘本"的味道，主插画改用 Codex 的生图功能画，风格要求：

- 手绘绘本：墨蓝细线描边 + 平涂低饱和色块 + 轻微纸张颗粒和印刷错版感，没有渐变和 3D。
- 色彩只用第三节色板（原站取色），绿色系占画面约四成，粉色不超过一成。
- 主题是"一个安静的小工作间"：一张老式书桌，桌上一台圆角显示器、一只机械小手（就是助手）、一叠便签、一个印章盒；窗外是傍晚的青绿天色和层层灰绿山丘（第四轮起），远处一点雾紫云。不出现原站的晶体、植物、岛屿、部落人物。
- 按图层出图（透明 PNG），方便分开做动画：
  1. 背景：窗外天空和城市剪影（1040 × 720，横向可裁切做视差）
  2. 中景：书桌和显示器
  3. 前景：机械小手（单独一层，要能移动）
  4. 道具：便签、印章（各一张小图）
  5. 托盘图标：64 × 64 的小印章造型，另出一张带玫瑰色角标的
- 每张图先出 2 个版本给用户挑。插画进程序时放 `agent/assets/illustrations/`，体积每张不超过 400KB。

## 八、动效

原则：每个动作都有回应；平时最多一个很慢的循环；系统开启"减少动态效果"时全部关掉，只保留状态变化。

| 时机 | 动效 | 时长 |
|---|---|---|
| 打开窗口 | 像翻开绘本封面：封面纸翻过去，露出整幅场景（方案二）；三联窗版是两扇侧窗向两边展开 | 450ms |
| 空闲 | 窗外天空极慢地横移（视差），便签角偶尔掀动一下 | 20 秒一个循环 |
| 开始任务 | 机械小手从桌边伸到显示器前，显示器亮起 | 600ms |
| 每一步 | 小手点一下屏幕，点击处出现一圈墨水涟漪 | 300ms |
| 一步做完 | 对白框旁冒出一个鼠尾草色小勾，0.6 秒后淡出（第四轮去掉了圆章） | 350ms |
| 状态换句 | 对白框旧句淡出，新句逐字打出 | 每字 25ms |
| 新的待处理 | 新签条被夹到晾绳上，玫瑰色木夹晃两下，数字角标加一；托盘图标角标闪一次 | 500ms |
| 恢复自动回复 | 签条被撕下并飘走，原位出现一个鼠尾草色小勾 | 500ms |
| 拖动画面 | 各图层按远近不同幅度位移，松手弹回正中 | 跟手；回弹 800ms |
| 停止任务 | 小手缩回桌边，显示器变暗，对白框写"已停止" | 400ms |
| 任务进行中 | 停止按钮外圈一道青绿细线慢慢转（代替进度圆章） | 2 秒一圈 |

PySide6 做法：位移、透明度用 `QPropertyAnimation`；涟漪和盖章用自绘加 `QVariantAnimation`；视差用多层 `QLabel` 叠放分别移动；减少动态效果读 Windows 的"显示动画"设置。

## 九、PySide6 能不能做

| 效果 | 做法 | 风险 |
|---|---|---|
| 纸纹底 | 一张 256×256 颗粒 PNG 平铺，`QWidget` 画背景 | 低 |
| 双线窗框和圆拱 | 自定义 `paintEvent` 用 `QPainterPath` 画，或整张 SVG 做背景 | 中：要处理窗口缩放 |
| 线稿插画 | SVG 文件，用 `QSvgWidget` 显示 | 低 |
| 错位投影 | 画两层矩形，不用模糊阴影 | 低 |
| 超粗字体 | `QFontDatabase.addApplicationFont` 加载随程序打包的字体 | 低：需确认许可 |
| 停止按钮外圈转线 | 自绘圆弧加 `QVariantAnimation` | 低 |
| 拖动视角 | 场景改用 `QGraphicsView`，各图层是 `QGraphicsPixmapItem`，按深度系数平移并加轻微透视缩放；不是真 3D | 中：要分清拖动和点控件 |
| 小宠物表情 | 眼睛、手臂单独图层，按 worker 事件切换和移动 | 中：手臂指向位置要和实际操作对应 |

## 十一、验收标准

- 第一节列出的控件，每张图里该出现的都出现了。
- 正文对比度 ≥ 4.5:1，小字不小于 12px。
- 插画是新画的，不出现原站的晶体、植物、岛屿等元素；不用原站字体文件。
- 动效演示里每个动画都对得上第八节的时机和时长，没有多余的装饰动画。
- 用户看完预览图选定后，才动程序。
