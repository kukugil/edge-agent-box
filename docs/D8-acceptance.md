## 微信：10 轮（通过线 ≥8 且 0 误发）

命令：`python -m agent.core.graph <白名单好友> "测试 N"`，N = 4…13，窗口 960×800，开始时停在目标会话。

| 项 | 结果 |
|---|---|
| 程序判定通过 | 8/10（第 3、6 轮判失败） |
| 实际发出（人工看聊天记录） | 10/10，每条只发一次，内容都对 |
| 误发（发错人、发错字、重复发） | 0 |
| 结论 | **通过** |

两轮失败都是**核对误判**：消息确实发出去了，`verify_sent` 没数到新气泡。下一步：回车后多等一会儿再截图，或重试一次再判。

调通过程中修的问题：
- 聊天区下沿 `CHAT_BOTTOM` 710 → 645（按 960×800 重量；原值把输入框算进聊天区）
- `count_before` 只在按回车前数
- 规矩加两条：没按过回车不许 done；不许点「发送」按钮（焦点会跑到按钮上）
- 提示词：输入框有字不算完成

已知局限：坐标线跟窗口大小绑定；这 10 轮都从目标会话开始，没测"从别的会话切过去"。
