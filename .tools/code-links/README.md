# 飞书周文档的代码链接（给 Claude 用）

用户说"代码推上去了，更新飞书链接"时，照下面做。

## 文件

| 文件 | 干什么 |
|---|---|
| `code_links.json` | 清单：飞书里每个格子链到哪个文件、哪个函数，格子在哪。**加了新事项就在这里加一项** |
| `code_links.py` | 按清单算出最新提交上的链接，和 `state.json` 比，列出要改的格子 |
| `state.json` | 飞书里现在实际写着的链接。只在飞书改完以后用 `--save` 更新 |

## 步骤

1. **确认代码已推送。** 脚本默认用 `origin/main`，没推送的提交它会直接报错。推送要用户同意（仓库是公开的）。
2. **列出要改的格子：** `python .tools/code-links/code_links.py --check`
   - 标"要改"的才动，"不变"的不碰。
   - 标"出错"的说明函数改名或文件挪了，先改 `code_links.json`，再重跑。
3. **在内置浏览器里改飞书**（方法见下一节）。改之前要登录，登录过期时请用户在浏览器面板里扫码。
4. **核对：** 截图看每个改过的格子是蓝色链接、内容对。
5. **记下来：** `python .tools/code-links/code_links.py --save`

## 改飞书格子的方法（踩过的坑）

浏览器窗口先设成 1400×1000；面板宽度一变，这个设置会被清掉，要重新设。

### 第 2、3 周：内嵌电子表格（画在画布上，读不出文字，只能截图看）

- **定位：** 点该行任意一格，再用方向键移到 E 列。点击时页面常会滚动，所以只靠方向键移动，每改一格前截图确认。
- **确认焦点：** `document.activeElement` 应该是 style 里有 `position: absolute; width: 50px` 的 contenteditable div。如果是 `docx-selection-hidden-textarea`，说明焦点在文档上，这时按 Ctrl+A 会选中整篇文档，**绝对不能打字**。
- **改一格：** F2 → 等 1 秒 → Ctrl+A（只选中这一格）→ 等 1 秒 → 输入网址 → Enter。网址会自动变成链接。
- **不要用：** 直接打字、粘贴、右键粘贴（会弹"未授权读取剪贴板"）、shift+Home（多行时只选中最后一行，会留下旧字）。
- 改错了按 Esc 取消编辑（这里是飞书网页，可以按 Esc）。

### 第 1 周：普通文档表格（DOM 里能读到文字）

- 表格是 `[data-block-type=table]`，格子按行依次排列，每行 5 格，"代码"列是第 5 格（下标 4、9、14、19、24、29）。
- **点击空格子没用**：会变成整格选中，打的字进了只读的隐藏框，什么都没写进去。
- **写空格子：** 先点一下别的有字的格子，让编辑器拿到焦点；再用 JS 把光标放到**左边那格文字的末尾**；按真实的 Right 键，光标会进入右边的空格；最后输入，末尾带一个空格，网址就会自动变成链接。
- **换掉已有链接：** 用 JS 选中这一格里的整段旧网址（文字可能拆在好几个文本节点里，起点和终点要分别找），然后直接输入新网址。
- 改完用 `innerText` 和 `querySelectorAll('a').length` 核对。按 Tab 键不会跳格，字会接到左边那格后面。

## 以后加新的一周

在飞书新一周的表格里先加好"代码（GitHub）"列：内嵌表格在 D 列列标上右键 →"向右插入 1 列"。然后在 `code_links.json` 里加上这一周的各项，`where` 写清格子位置。
